# Ouroboros RPG – Un Mensaje de Arte (medios)

Arte generado con IA (ComfyUI, SDXL + ControlNet) para un one-shot de horror cósmico ambientado en París, 1892, jugado con el sistema de cartas **Ouroboros RPG**.

Cada pintura existe en dos versiones: la **original** (simbolismo de 1890, óleo) y su **contraparte macabra**. El vídeo hace un morph entre ambas.

| 02 | El Hombre y el Toro |
| 03 | El Minotauro |
| 04 | Los cinco mil |
| 05 | El Fénix |
| 06 | La cabaña de Thoiry |
| 07 | El Kraken |
| 08 | Las Musas |
| 09 | Cartel Rosacruz |

Rutas: `original/<id>.png`, `macabra/<id>.png`, `video/<id>.mp4`, con el id completo (por ejemplo `01_bathsheba`).

**Aviso para jugadores:** si vas a jugar la aventura, no abras las carpetas `macabra/` ni `video/`: son spoilers.

## Créditos y licencia
