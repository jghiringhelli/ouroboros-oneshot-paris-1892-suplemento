# Ouroboros RPG – One-shot París 1892: suplemento gratuito de arte

Suplemento **gratuito y no oficial** para un one-shot de horror de investigación, ambientado en el París de 1892 y jugado con **Ouroboros RPG**. Solo contiene arte generado con IA (ComfyUI, SDXL + ControlNet).

**No incluye texto de aventura.** Es un extra para quien ya tenga la aventura original: comprad vuestros PDF o libros. Este material se inspira en *A Message of Art*, de *Nameless Horrors* (Chaosium, para Call of Cthulhu); Chaosium es titular de sus derechos y este repositorio no está afiliado a ella.

Arte generado con IA (ComfyUI, SDXL + ControlNet) para un one-shot de horror cósmico ambientado en París, 1892, jugado con el sistema de cartas **Ouroboros RPG**.
